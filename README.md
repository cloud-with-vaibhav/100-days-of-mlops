## 🚀 Quick Start

To use this repository as a reference for your own learning:

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/100-days-of-mlops.git
cd 100-days-of-mlops
```

### 2. View Today's Solution
```bash
cat Day-01/README.md
```

### 3. Implement the Task
Follow the step-by-step instructions in each day's README file.

### 4. Set Up Your ML Environment (Day 1)
```bash
cd /root/code
python3 -m venv ml-env
source ml-env/bin/activate
pip install numpy pandas scikit-learn matplotlib
pip freeze > requirements.txt
```
